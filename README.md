# Crochet Classifier

Um classificador de imagens (visão computacional) para detectar erros em
peças de crochê — ponto pulado, tensão irregular, borda deformada, entre
outros — construído com PyTorch.

> **Estágio atual: dados sintéticos (mock).** As imagens usadas até
> agora são geradas artificialmente por script, não são fotos reais de
> crochê. Veja a seção [Por que dados mockados?](#-por-que-dados-mockados)
> para entender o motivo.

---

## Sobre o projeto

O objetivo final é treinar um modelo capaz de olhar para a foto de uma
amostra de crochê e classificá-la como **correta** ou **com erro**
(ponto pulado, aumento indevido, diminuição indevida, tensão irregular,
borda deformada, etc.).

Este é um projeto de longo prazo, dividido em fases:

- **Fase 1** — Prova de conceito: um único fio, agulha e ponto,
  ~100 amostras físicas, classificação binária (correto/erro)
- **Fase 2 (atual)** — Pipeline de código completo (carregamento, augmentation,
  treino, avaliação)
- **Fase 3** — Expansão do dataset (mais fios, cores, pontos, agulhas)
- **Fases futuras** — Localização do erro na imagem, classificação do
  tipo específico de erro, reconhecimento estrutural (carreiras,
  contagem de pontos), e eventualmente um sistema mais completo de apoio
  à modelagem em crochê

## Por que dados mockados?

Fabricar e fotografar 100 peças físicas de crochê, com protocolo
padronizado (fundo, iluminação, ângulo), leva tempo — e não precisa
travar o desenvolvimento do código.

Existe uma diferença entre **"o código funciona sem bugs"** e
**"o modelo aprende algo real sobre crochê"**. A primeira parte pode
(e deve) ser validada agora, em paralelo à fabricação das peças reais.

Por isso, o pipeline atual usa imagens **sintéticas**, geradas por
[`scripts/gerar_mock.py`](scripts/gerar_mock.py): padrões simples de
linhas repetidas simulam a classe "correto", e o mesmo padrão com uma
linha deslocada ou faltando simula a classe "erro". Essas imagens não
ensinam nada sobre crochê real — elas só replicam a mesma estrutura de
pastas e formato de arquivo que as fotos reais vão ter.

**Quando as fotos reais chegarem:** basta substituir o conteúdo das
pastas `dataset/correto/` e `dataset/erro/` pelas fotos de verdade e
rodar o mesmo pipeline, sem alterar nenhum código.

# Crochet Classifier

An image classifier (computer vision) for detecting errors in crochet pieces — 
skipped stitches, irregular tension, deformed edges, among others — built with PyTorch.

> **Current stage: synthetic (mock) data.** The images used so far are
> artificially generated by a script and are not real crochet photographs.
> See the section [Why mock data?](#-why-mock-data)
> to understand why.

---

## About the project

The final goal is to train a model capable of looking at a photo of a
crochet sample and classifying it as **correct** or **with error**
(skipped stitch, improper increase, improper decrease, irregular tension,
deformed edge, etc.).

This is a long-term project, divided into phases:

- **Phase 1** — Proof of concept: a single yarn, hook, and stitch,
  ~100 physical samples, binary classification (correct/error)
- **Phase 2 (current)** — Complete code pipeline (data loading, augmentation,
  training, evaluation)
- **Phase 3** — Dataset expansion (more yarns, colors, stitches, hooks)
- **Future phases** — Error localization in the image, classification of
  specific error types, structural recognition (rows,
  stitch counting), and eventually a more complete system to support
  crochet pattern design

## Why mock data?

Making and photographing 100 physical crochet pieces, with a standardized
protocol (background, lighting, angle), takes time — and it does not need
to stop code development.

There is a difference between **"the code works without bugs"** and
**"the model learns something real about crochet"**. The first part can
(and should) be validated now, in parallel with the production of the real pieces.

For this reason, the current pipeline uses **synthetic** images generated by
[`scripts/gerar_mock.py`](scripts/gerar_mock.py): simple patterns of
repeated lines simulate the "correct" class, while the same pattern with a
shifted or missing line simulates the "error" class. These images do not
teach anything about real crochet — they only replicate the same folder
structure and file format that the real photographs will have.

**When the real photographs are ready:** simply replace the contents of the
`dataset/correto/` and `dataset/erro/` folders with the real photographs and
run the same pipeline without changing any code.
